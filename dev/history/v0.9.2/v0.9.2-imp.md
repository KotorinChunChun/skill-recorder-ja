- [x] 録画、設定、録画操作バー、プライバシー説明とターミナルを翻訳し、ビルドを確認する。
- [x] セッション一覧、解析、AI 接続、スキルと自動化の作成を翻訳し、テストする。

## 検証結果

- Node.js 24.22.3 でアプリケーションの型検査とリリース用ビルドに成功した。
- Windows で既存テスト302件が成功した。サンドボックス内の初回は Copilot CLI の展開が権限エラーで停止したため、通常の Windows 環境で再実行した。
- Windows の Electron をテスト専用プロファイルで起動し、録画、設定、プライバシー確認、セッション一覧と AI 接続の日本語表示を確認した。合成セッションで解析結果、作成対象の選択、スキルと自動化の作成画面を確認した。実際の録画と AI による解析は行っていない。
- 検証時は録画のグローバルショートカットを登録できなかった。画面のボタンから録画を開始できる。
- ライセンス資料を生成し、デスクトップとスタートメニューに「Skill Recorder 日本語版」のショートカットを登録して参照先を照合した。
- 日本語版を起動引数なしで開く場合は %APPDATA%\skill-recorder-ja に録画や設定を保存する。外部プログラムや OS から返された診断の詳細は、元の言語で表示されることがある。

## このPCの公式版からの切り替え

- 録画が停止中であることを画面で確認し、公式版を終了した。
- デスクトップとスタートメニューの日本語版ショートカットを、公式版と同じ %APPDATA%\skill-recorder を使う設定に変更した。旧ショートカットはこの版のログフォルダーに退避した。
- 日本語版を起動し、録画画面と端末内の保護モデルが利用可能と表示されることを確認した。

## 文字起こしの既定言語

- [x] OS の優先言語のうち、文字起こしが対応する最初の言語を起動時に選ぶ。該当するものがなければ英語にする。
- [x] 録画設定に「既定（言語名）」を表示する。言語を手動で選んだ場合はアプリの設定として保存し、「既定」を選び直すと OS の言語に戻す。
- [x] 新規の動画読み込みの初期値に OS の優先言語を使い、保存済み録画と読み込み済み動画にはそれぞれ保存されている言語を使う。
- [x] ビルドと Windows のテスト303件が成功した。隔離プロファイルで「既定（日本語）」の表示、保存済みの手動設定の読み込み、既定への復帰を確認した。録画で使用する言語はテスト用の音声レコーダーで検証した。
